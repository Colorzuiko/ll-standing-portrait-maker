# 表情、眼嘴與肢體協調

本文件補充正式 60 表情及 [肢體 v2](body-language-catalog-60-v2.md)。原肢體清單為 43 新增／17 沿用；使用者指定「新版肢體」時選 v2 的 35 新增／25 沿用，並在計畫中記錄所選版本。

## 53、60：單眼眨眼

動畫的休止 0 格是雙眼睜開。先依角色參考選定閉合側，再固定使用同一眼；左右以角色自身為準，鏡像顯示不改變來源閉合側。

| 格 | 指定眼 | 另一眼 |
| --- | --- | --- |
| 0 | 睜開 | 睜開 |
| 1 | 半閉 | 睜開 |
| 2 | 閉合 | 睜開 |
| 3 | 半睜 | 睜開 |

之後回 0；設 `eyeAuto=true`。不能把動作峰值 2 格當成固定休止狀態，也不能套成雙眼同閉。53 與 60 分別保持自己的嘴形與情緒。

## 60：吐舌嘴形

嘴 0 格為閉嘴、沒有舌頭；1 格舌尖、2 格部分伸出、3 格最長伸出。眼睛與嘴巴各自計時，不要求永遠同格播放。檢查 16 個眼嘴組合、OFF 回休止格，並確認舌頭不穿出既定嘴形區或改動下顎。

## 靜態檢查與動畫工作圖

三種「四格」不可混用：靜態表情批次的2×2每格是不同表情；肢體定格的2×2是同一表情的四個身體動作階段；固定姿勢眼嘴工作圖的4×1是同一臉部裁切範圍的四個眼嘴狀態。肢體四格可獨立製作，不要求先完成臉部動畫。肢體圖集若重排為4×1，是裁切後的交付格式，不改變2×2生成工作圖。

靜態檢查若選用53／60的眨眼峰值或吐舌格，記錄`representative_frame`，不據此改寫眼嘴動畫休止規則；只有靜態PNG時不宣稱已交付眨眼／嘴型圖集。需要固定姿勢的獨立眼嘴與LL播放時使用眼嘴流程。

## 表情與接觸

- 21 是嘆氣，不加牌子。16、29、30、34、42 保留正常五官與溫和漫畫表現；原設定的正常紅眼不等於恐怖發光眼。
- 33、48 是睜眼笑，普通眨眼可暫時閉合；28 吃痛瞇眼與固定符號眼不套通用雙眼眨眼。
- 44 為臉部去飽和，50 為上半臉藍灰壓力陰影；眉眼、嘴形及局部色調須保留各自語意。
- 嘴角外側撐笑、單側擦淚、覆嘴，以及碰耳側／髮際的動作，均檢查手指與臉髮遮擋。固定頭部合成不能清掉前景手指，也不能把眼嘴疊到手背上。
- 動作表中的胸前配件、披風、腰帶或槍套屬角色參考語境。依本次主設定圖保留實際服裝與配件，不因提示提到胸針而替沒有胸針的角色添加胸針。

JSON 快照中的 `eye_motion`、`mouth_motion` 是製作規格；實際閉合側、座標、遮罩與圖檔仍需依每次母圖量測及驗收，不能由文字欄位推定已完成素材。
