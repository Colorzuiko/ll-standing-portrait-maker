# 選用的分層／局部差分製法

預設仍是同畫布2×2的完整人物四個階段。只有本次要求或已選定局部／分層方案時才採用本變體；它不會自動取代使用者喜歡的舊版。

1. 凍結已接受角色與構圖，分成靜態底層、可能移動的手臂／衣料區、臉部接觸保護區。先移除底層原有手臂並補完被遮住的衣服，避免疊出雙手或殘影。
2. 依同一四階段，在同畫布2×2繪製局部動態層。四格必須共用局部裁切框及回貼座標；需要縮放時只做一次共同對應，保留原圖。
3. 動態層保留RGBA，允許移動輪廓及新露出的衣料改變alpha。只對真正靜止的區域檢查不變，不可使用「整張alpha固定、只改RGB」的眼嘴合成契約處理移動手臂。
4. 接觸臉部時明確指定前後層順序。食指在嘴角外側向上推臉頰，必須同時檢查指腹接觸、臉頰變形及遮擋；單純把手貼在臉前不等於完成動作。必要的臉部接觸差分可烘焙到該肢體格，不生成獨立眼嘴圖集。
5. 將四格動態層各自按固定座標合成回靜態底層，再交付四張完整720×720。檢查肩關節、腋下、髮絲、手指與護甲接縫，避免固定邊界造成僵硬或手臂截斷。

記錄來源、靜態底層、局部原圖、共同映射、動態遮罩、合成順序、四張合成結果與預覽。附帶的分格／打包工具不會替你完成移除舊手、修補底層或建立動態遮罩。

比較時同時看定格與循環。差分通常能減少非動態區漂移，但不保證動作更自然、算圖更省或使用者更喜歡；評估還需計入補底、接縫修正、重生次數及額外圖層容量。使用者選擇其他版本時，保留試驗與紀錄，將選擇寫回該角色／動作，不推廣成所有角色的禁用規則。
